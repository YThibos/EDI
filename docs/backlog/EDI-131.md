## Goal

Every GitHub Action in the repository's workflows is pinned to a full commit SHA, with its tag in a comment, and Renovate keeps the digests current.

## Context

The workflows pin actions to tags, which a maintainer can move.
This matters once the repository is public, because workflows then run on code the repository does not control.
Severity: informational, and required before the repository is made public.

## Acceptance criteria

- Every `uses:` line in `.github/workflows` names a full commit SHA, with the tag it stands for as a comment on the same line (a comment explaining a pin is allowed here, as a suppression justification is).
- Renovate's `pinDigests` is enabled in `renovate.json` so the digests stay current.
- The SHAs are verified against the actions' repositories, not guessed; a sandbox without network access says so and asks on the issue.

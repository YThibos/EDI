  The captain folded EDI-94 into EDI-161, with the core's measured minutes booked once and the status driven from the stored stage through [EDI-163](EDI-163.md)'s walk, which EDI-161 now waits on.
  Booking "once" is written as the minutes up to the done at the done and the minutes after it at cleanup, so fix rounds are booked and no minute twice.
- [EDI-157](EDI-157.md) said itself that [EDI-86](EDI-86.md) probably cures it; the captain folded it into EDI-86, which now carries its criteria.
- [EDI-69](EDI-69.md), a standing note that CI is unavailable, was written for the Actions billing block, which is over, and the registry's `ciRuns: false` already covers a project without CI for [EDI-148](EDI-148.md); the captain dropped it, and EDI-148 no longer waits on it.
- [EDI-118](EDI-118.md)'s criterion to make Renovate run without Actions is obsolete: Renovate's scheduled workflow ran on 3 November 2026; the captain dropped that criterion.
- Seven of EDI-52's console slices waited on [EDI-89](EDI-89.md) only because wave 5 was set to start after plans dispatch themselves: [EDI-55](EDI-55.md), [EDI-56](EDI-56.md), [EDI-57](EDI-57.md), [EDI-58](EDI-58.md), [EDI-63](EDI-63.md), [EDI-64](EDI-64.md) and [EDI-66](EDI-66.md); the captain lifted that wait for them.

- The pickup protocol said Actions does not run here; it now asks for the pull request's CI run to be green before the pull request is marked ready, and makes a CI failure the session's to fix.
- `folded` and `dropped` are added to the statuses.

## Goal

The publish-check endpoint runs git only in a registered project's clone or a task's isolated copy, and only for callers the other endpoints accept.

## Context

The publish-check route has no caller restriction and runs git in any absolute path it is given.
The board host also receives a board path as an argument for the board tool, although arming a board already confines boards to the task directory.
Severity: low.

## Acceptance criteria

- A failing test first shows the endpoint running in an arbitrary absolute path.
- Only a registered project's clone or a task's isolated copy is accepted, compared by real path; anything else is refused with a reason.
- Callers are restricted as the other endpoints are.
- A test pins that the board host receives only paths inside the task directory.

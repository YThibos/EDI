## Goal

The console accepts only requests addressed to its own loopback host and port, and refuses to be framed by any page.

## Context

There is no Host-header check, no content security policy and no frame option.
DNS rebinding reaches only the health route, the console session route (which needs a 256-bit token) and static files.
But any page on the same loopback address at another port, such as a worker's development server, is same-site, receives the strict same-site cookie and can frame the console, which allows clickjacking.
Severity: low.

## Acceptance criteria

- A failing test first shows a request with a foreign Host header being served.
- Only `Host: 127.0.0.1:<port>` and `localhost:<port>` are accepted; anything else is refused.
- Every response carries `frame-ancestors 'none'` in its content security policy and `X-Frame-Options: DENY`.
- Tests cover accepted hosts, refused hosts and the two headers, and the access record gains a history line.

## Goal

The console's one-time sign-in link is handed to the browser without ever appearing on a process command line, and its copy in the primary's transcript is justified or removed.

## Context

The captain's browser is opened with a command that carries the full sign-in address, token included, which is visible in the process list while the link lives (two minutes, single use).
The opening text also prints the link into the primary's transcript.
Severity: low.

## Acceptance criteria

- A failing test first shows the link in the argument list of the launched process.
- The link reaches the browser without being on a command line: for example a short-lived local file the browser opens, or the standard input of a helper.
- A decision is made and recorded on whether the transcript copy is needed; if removing it changes what the captain sees, ask on the issue first.
- Tests pin that no launched process carries the token in its arguments.

## Requirements from decisions and answers

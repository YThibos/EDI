## Goal

The primary's tmux status bar shows the whole session name, and EDI gets real release versions, starting with a first 1.0.0, shown in the status bar and the console.

## Context

The primary's tmux session shows only 10 characters of its name, tmux's default status-left length, so a name such as `edi-261028-0728` reads as the first ten characters followed by the window.
The captain also asked for EDI versioning, judging EDI beyond alpha and beta with a solid first release.
This item is held until the captain's word.

## Acceptance criteria

1. `edi up` sets the status-left length wide enough for the whole session name, for that session only.
2. EDI gets real release versions, a first 1.0.0, shown in the status bar and the console.
3. The session name stays `edi-<yymmdd>-<hhmm>` per launch, because an external terminal integration matches that pattern.
4. No `-SNAPSHOT` version in any `pom.xml`.

## Requirements from decisions and answers

- The captain (28 October 2026): add one backlog ticket that includes both the status bar width fix and the EDI release versioning.
- The session name pattern is fixed: `edi-<yymmdd>-<hhmm>`.
- Reaching 1.0.0 ends the rule that nothing legacy lingers below version 1.0.0: record in the decision log how that changes (compatibility after 1.0.0), if it does.

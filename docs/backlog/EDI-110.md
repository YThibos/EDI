## Goal

While the core does not answer, the console header hides its stardate and machine slots, or shows a clear "core unreachable" state, instead of bare placeholders.

## Context

EDI-82's test step saw, with the core not answering, bare dash placeholders in the stardate and machine slots at the top right of the console header.
This item is held until the captain's word.

## Acceptance criteria

- In the state where the core does not answer, the stardate and machine slots are hidden, or show a clear "core unreachable" state.
- Checked in a browser at desktop and phone widths, with what was seen described in the pull request.
- A component test pins the state.

## Requirements from decisions and answers

- The console fits 1920 by 1080 at 100% and 125% ([console-look](../decisions/console-look.md)); the header must not shift layout between the two states.
- Text speaks as EDI in the first person if it speaks at all.

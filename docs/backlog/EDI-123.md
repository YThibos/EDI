## Goal

A worker can never inject input into the captain's primary session, on any tmux socket and by any tmux command, so typed text can never count as the captain's word through a worker.

## Context

The tmux socket guard refuses kill, send and respawn only on EDI's own socket, but the primary runs on the default tmux server.
So `tmux -L default send-keys -t <primary> ... Enter` passes the guard, and the typed text arrives as a prompt submission that counts as the captain's word.
The edi-socket rule is also bypassed by `set-buffer` with `paste-buffer`, `source-file`, `run-shell` and `if-shell`, and by a symlinked `-S` path, because only the last path segment is compared.
Severity: medium.

## Acceptance criteria

- A failing test first reproduces the injection through the default server.
- For workers, every input-injecting tmux command is refused on any socket: `send-keys`, `paste-buffer`, `source-file`, `run-shell`, `if-shell` and the like.
- A `-S` socket path is resolved to its real path before it is compared.
- A decision is made and recorded on whether a typed prompt should remain the only evidence of the captain's word; if the question changes scope, ask on the issue first with lettered options and a recommendation.
- Tests pin each refused command and the symlink case, and the guard record is rewritten with a history line.

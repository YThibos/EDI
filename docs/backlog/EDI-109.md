## Goal

When a worker runs the dependency-vulnerability build, the NVD API key is set for that command only, read at call time from the secrets file the machine profile names, and never visible to the worker.

## Context

The captain's one secrets file holds the NVD key under a flat top-level key; EDI's `pom.xml` reads `NVD_API_KEY` from the environment, so the build needs it.
Workers must never see or print secret values (I-32, and the Read guard of EDI-80).
The captain chose option C: an interim login export now, then EDI hands the key to worker builds at call time.
The interim is a block in the captain's shell start-up file that exports the variable at login.

## Acceptance criteria

- When a worker runs the dependency-vulnerability build, `NVD_API_KEY` is set for that command only, read at call time from the secrets file path the machine profile names (not a path in the repository).
- The value never appears in a brief, a log, a transcript or the event store.
- Tests with a stand-in secrets file.
- The docs tell the captain to remove the interim shell start-up block once this lands.

## Requirements from decisions and answers

- Option C (captain, 27 October 2026): an interim login export now, then EDI hands the key to worker builds at call time.
- Secrets are read at call time and never printed (I-32); the key never reaches a worker's own environment or tool output.
- Machine differences come from the machine profile at runtime ([machine-and-person-specifics](../decisions/machine-and-person-specifics.md)).
- Tracked files name no path or key; use invented ones in tests.

## Research and measurements

- The pom reads `nvdApiKeyEnvironmentVariable` as `NVD_API_KEY`; the dependency check fails at CVSS 7 or above ([dependency-upkeep-and-scanners](../decisions/dependency-upkeep-and-scanners.md)).

## Not for the cloud session

The feature reads the captain's secrets file, which exists only on his machine, and the work touches how secrets are handled.
The cloud session has no such file and must never be given one.
It is listed as needs-captain-machine, and it is held until the captain's word.

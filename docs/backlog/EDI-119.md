## Goal

The core's default port becomes 5490, outside the ephemeral ranges, and `SERVER_PORT` still overrides it.

## Context

The core listens on a fixed default, 47318, set in `edi-core/src/main/resources/application.yaml`, which is hard to remember and lies inside the captain's machine's Linux ephemeral port range, so an outgoing connection can hold it when the core starts.
With mirrored networking the core also shares ports with Windows, whose dynamic range is 49152 to 65535.
5490 stands for E, D and I as the 5th, 4th and 9th letters of the alphabet, and it was checked free on the captain's machine on 28 October 2026.

## Acceptance criteria

- The default port becomes 5490 in `application.yaml`, and every file that names 47318 follows: the README, `docs/architecture.md`, `docs/configuration.md`, the access record and the tests that name it.
- The access record says what the code does (the port comes from `application.yaml` and `SERVER_PORT`, not from the machine profile) and why 5490 was chosen.
- When the port is taken at start, the core fails with a message that names the port and `SERVER_PORT`, pinned by a test.
- Offline verification: the local verify, the native quick build and the publish check, with results in the pull request body.

## Requirements from decisions and answers

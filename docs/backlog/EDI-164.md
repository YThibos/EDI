## Goal

The weekly gardening can see which rules fire, how often and on what, which never fire, and how the core itself performs, from recorded data rather than impressions.

## Context

The captain wants a weekly gardening routine that measures how often each rule fires, if ever, and which silent failures and slips cost time or tokens, so they become hard rules.
Today no refusal, guard or hook leaves a uniform record: some write events, some only print, and the anchor's and memory's soft rules leave nothing at all.
The captain also asked that the core itself be measured, with JDK profiling and telemetry.
Priority: second, straight after EDI going public (EDI-132 and the security items before it).

## Acceptance criteria

- Every refusal, guard, hook block and validation in the core, the CLI and the hooks emits one `rule-fired` event with a stable rule id, the task or session, the outcome (refused, warned, allowed after a check) and a short reason; a catalogue lists every rule id with where it lives and what it protects.
- `edi rules` prints, for a period, each rule's fire count, its last firing, and the rules that never fired; `--json` for scripts.
- The core records its own health: a continuous JDK Flight Recorder recording with a bounded size (or the native image's equivalent where JFR is unavailable), and Micrometer metrics for request latency per endpoint, wake delivery latency (raised to printed to acknowledged), store query time, supervision round duration, worker launch time and memory; `edi health --metrics` shows the week's summary, and a recording can be dumped on demand for profiling.
- Telemetry stays local, contains no secret and no personal content, and passes `edi publish-check` rules; nothing is sent anywhere.
- Collecting it costs no model tokens.
- Tests cover the event shape, the catalogue's completeness (a rule without an id fails the build), `edi rules`, and the metrics endpoints.

## Requirements from decisions and answers

- Soft and silent failures are covered by hard rules that are non-negotiable and non-bypassable; measuring what fires is how the gardening proves it.
- EDI goes public first; this is the clear second priority.
- Nothing secret or personal is ever pushed or sent.

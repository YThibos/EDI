# EDI-131 CI actions are pinned to commit SHAs

## What it changes

Every GitHub Action in the repository's workflows is pinned to a full commit SHA, with its tag in a comment, and Renovate keeps the digests current.

The commits, in order:

- Read a captured log event without a message as an empty line
- Pin every GitHub Action to a full commit SHA with its tag and let Renovate keep the digests
- Record why actions are pinned to commit SHAs
- Mark the item delivered

## How it was verified

Its commits landed on `main` through #83, after the repository's build and tests passed there.

# EDI-129 The EDI home and its store are readable by the captain only

## What it changes

The EDI home is created owner-only, its files too, and an existing home is repaired when the core starts.

The commits, in order:

- Keep the EDI home for its owner alone: closed at install, repaired at each start, and the core started under umask 077
- Date the record line by the day it was written
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image.

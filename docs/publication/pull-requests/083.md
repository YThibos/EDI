# EDI-125 EDI-131 Hooks guard and SHA-pinned CI actions, together on today's main

## What it changes

A worker cannot turn its guard hooks off by writing local Claude Code settings in its own copy.

The commits, in order:

- Read a captured log event without a message as an empty line
- Pin the hooks on in the launch settings and refuse a worker writes under its copy's .claude directory
- Record the verification that local settings switch hooks off and the guard that answers it
- Mark the item delivered
- Pin every GitHub Action to a full commit SHA with its tag and let Renovate keep the digests
- Record why actions are pinned to commit SHAs
- Drop trailing blank line from Claude Code verification notes

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

# EDI-122 A worker can never act as the primary by dropping its token file

## What it changes

A worker can never act as the primary by leaving out its own token file, so the claim that a misled worker cannot act as the primary holds.

The commits, in order:

- Refuse a worker's window the home token and keep its identity variables from its shell
- Record what keeps a worker from acting as the primary and what still cannot
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

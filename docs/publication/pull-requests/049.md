# EDI-54 Measure each task's active time from its timeline

## What it changes

The commits, in order:

- Measure each task's active minutes from its timeline
- Stop counting limit waits and drop ledger wall clock
- Count work resumed on a received steer
- End a worked stretch when the worker's turn ends
- End a stretch at a missed stop's transcript time
- Date a missed usage limit at the transcript's stop time

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

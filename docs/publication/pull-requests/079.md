# EDI-123 A worker can never type into the captain's primary session or reach the edi tmux socket another way

## What it changes

A worker can never inject input into the captain's primary session, on any tmux socket and by any tmux command, so typed text can never count as the captain's word through a worker.

The commits, in order:

- Read a captured log event without a message as an empty line
- Refuse a worker every tmux command that sends input to a pane and compare socket paths on their real path
- Record that a typed prompt stays the captain's word and what the guard now keeps from workers
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

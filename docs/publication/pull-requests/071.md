# EDI-100 Pin GraalVM, move the build to Maven 4 and start workers on their copy's toolchain

## What it changes

The commits, in order:

- Start every worker on its copy's pinned toolchain through mise exec
- Move to GraalVM Community 25.4.4.1.1, Node 26.12.1 and Maven 4.0.0-rc-7 on model 4.1.0
- Trust the copy's mise configuration when a worker starts
- Ask for mise trust once per clone and drop the unused Mockito
- Bump Spring Boot 4.1.2, mise-action, Renovate action; drop Tomcat override
- List mise among the tools EDI drives
- Trust a worker's copy only when mise trusts its clone
- Start workers through mise exec only for trusted clones
- Count only the clone's own mise configurations as trust

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

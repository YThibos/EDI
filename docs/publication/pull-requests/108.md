# EDI-151 Backlog: Stopping a worker also ends the processes it left behind in its copy

## What it changes

`edi worker stop` leaves nothing running in the worker's isolated copy, so `edi worker relaunch` never has to wait on, or be refused by, a process the worker started and orphaned.

The commits, in order:

- Add the backlog item: Stopping a worker also ends the processes it left behind in its copy
- Name the issue of the backlog item

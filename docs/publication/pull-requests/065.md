# EDI-104 Skip the rebase step in every worker pipeline run, and CI where it does not run

## What it changes

The commits, in order:

- Skip the pipeline's rebase and merge the base in with a merge commit
- Base a no-CI project's done on local verification
- State the no-CI ready-for-review rule everywhere
- Record the skipped pipeline steps in supervision history
- Align native-build and delivery docs with skipped pipeline steps
- Narrow the never-merge rule to merges into main
- List skipped pipeline steps in the tooling table

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

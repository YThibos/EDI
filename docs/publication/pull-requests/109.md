# EDI-143 Every state-changing edi command answers --json on the native core

## What it changes

Every `edi` command that changes state answers `--json` on the native `edi-core` as it does on the JVM core, instead of failing with a 500.

The commits, in order:

- Bind every confirmation record, and every case of a sealed part of one, for the native core's JSON answers
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image.

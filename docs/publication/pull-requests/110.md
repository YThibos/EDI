# EDI-126 The console checks the Host header and refuses to be framed

## What it changes

The console accepts only requests addressed to its own loopback host and port, and refuses to be framed by any page.

The commits, in order:

- Refuse a request addressed to any host but the core's own loopback address and port, and forbid every page to frame an answer
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

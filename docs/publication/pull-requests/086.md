# EDI-142 Put EDI work on the upstream backlog in one scripted step

## What it changes

The commits, in order:

- Add the edi-backlog-item skill, which puts work on the EDI project on the upstream backlog in one scripted step
- Unique backlog orders, resumable reruns, search-free issue lookup
- Rename nextOrderIn to orderOfANewRowIn
- Keep backlog orders unique across open branches, refuse reused keys
- Read the new task id from plain edi task add
- List the edi-backlog-item skill in the Claude layer doc

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

# EDI-128 Shell snippets built from configuration validate what they interpolate

## What it changes

Every shell snippet built from configuration or from a repository's remote validates and quotes what it interpolates.

The commits, in order:

- Read a forge host and a remote's host only as a DNS name, and quote the host and account in the credential helper
- Date the record lines by the day they were written
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image.

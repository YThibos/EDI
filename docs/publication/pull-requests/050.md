# EDI-53 Hold a handed-over request as changing while it still changes

## What it changes

The commits, in order:

- Hold a handed-over request as changing while its pipeline runs or a steer waits
- Keep observing a handed-over task's running pipeline
- Hold a resumed worker's open request as changing
- Read an accepted done from the event log alone
- Record handed-over pipeline observation in supervision record

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image, and CI ran on the pull request.

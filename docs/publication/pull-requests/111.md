# EDI-127 The console's sign-in link never appears on a process command line

## What it changes

The console's one-time sign-in link is handed to the browser without ever appearing on a process command line, and its copy in the primary's transcript is justified or removed.

The commits, in order:

- Hand the console's sign-in link to the browser through a short-lived owner-only page instead of a command line
- Mark the item delivered

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image.

# EDI-169 Open the console through a once-only http hand-off address so Windows' default web browser opens it

## What it changes

The commits, in order:

- Open the console through a once-only http address of the console, so Windows' default web browser opens it
- Expect the native core to open the console's http address beside Windows
- Describe the console's once-only http hand-off in the guide

## How it was verified

The repository's build and tests, `./mvnw verify`, passed before the merge, with the native build where the change could reach the native image.

A small helper, withoutClosingHashes, now removes the closing `#` marks that the old lazy regex trimmed. - StowList (java:S3655, twice, Optional read without a check): `entry.dated()` is now held in a local Optional, so the isEmpty check and the get() calls use the same value. - WeeklyUpkeep (java:S8696, `==` on a value-based type): the day comparison now uses `UPKEEP_DAY.equals(day.getDayOfWeek())`. After the fixes, the local run exits 0, so every test passes, and the gate reads OK: reliability, security and maintainability ratings are all A, and duplication is 0.2%.
